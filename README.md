# Relato Temporal

Site institucional da Relato, com uma aplicação React para a área pública e uma API Node.js preparada para os artigos do blog.

## Estrutura

- `apps/web`: front-end React + Vite.
- `apps/api`: API Express, inicialmente apenas para leitura de posts.
- `docs`: materiais de marca e referências fornecidas pelo cliente.

## Ambiente local

```bash
npm install
npm run dev:web
npm run dev:api
```

O site abre em `http://localhost:5173` e a API em `http://localhost:3001`.
